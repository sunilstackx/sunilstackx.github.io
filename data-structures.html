Data structures

A data structure is a way to organize information so a program can work with it. Different structures are useful for different jobs.

1. Arrays and lists

A list keeps items in order and lets you access them by position.

colors = ["red", "green", "blue"]
print(colors[0])  # red

2. Stack: last in, first out

Think of a stack of plates: the last plate placed on top is the first one removed.

stack = []
stack.append("A")  # push
stack.append("B")
last = stack.pop()  # removes B
A stack is useful when you need to undo actions or track nested work.

3. Queue: first in, first out

A queue handles items in the order they arrive, like a line of people.

from collections import deque
queue = deque(["A", "B"])
first = queue.popleft()  # removes A

4. Linked lists

A linked list is made of nodes. Each node stores a value and a link to the next node. It can be useful when inserting or removing items in the middle, though many everyday programs use arrays or built-in lists instead.
