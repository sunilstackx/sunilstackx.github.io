# SunilStack

A responsive, static programming learning site built with plain HTML, CSS, and JavaScript. It can be hosted for free with GitHub Pages.

## Pages included
- Home page with topic cards and an author introduction
- Python basics
- Java basics
- SQL basics
- Data structures

## Publish on GitHub Pages
1. Create a public repository named `sunilstackx.github.io` on GitHub.
2. Upload the contents of this folder (the `index.html`, `style.css`, `script.js`, and `lessons` folder) to the repository root.
3. In the repository, open **Settings → Pages** and set the source to **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. After GitHub finishes publishing, visit `https://sunilstackx.github.io/`.

You can edit the page text directly in the HTML files. This site has no paid services or server-side dependencies. The fonts are loaded from Google Fonts; system fonts will be used if those are unavailable.
