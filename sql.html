SQL basics

SQL is a language for working with data in relational databases. MySQL is one database system that understands SQL.

1. Read data

Use SELECT to choose columns from a table.

SELECT name, city
FROM students;

2. Filter rows

Add a WHERE clause to keep rows that match a condition.

SELECT name, city
FROM students
WHERE city = 'Dubai';
Text values in SQL are usually written inside single quotes. End each statement with a semicolon.

3. Sort results

SELECT name, score
FROM students
ORDER BY score DESC;

4. Add a row

INSERT INTO students (name, city)
VALUES ('Sam', 'Dubai');
