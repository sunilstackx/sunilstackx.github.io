JAVA · BEGINNER

Java basics

Java is a widely used programming language. These examples introduce the shape of a Java program and a few core ideas.

1. Your first program

A Java program starts running from its main method.

class Main {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}

2. Store information

Declare a variable with its type, then give it a value.

String name = "Sam";
int age = 20;
System.out.println(name + " is " + age);
Java checks variable types, so a value must match the type you declared.

3. Make a decision

int temperature = 25;
if (temperature > 20) {
    System.out.println("It's a warm day");
} else {
    System.out.println("It's a cool day");
}

4. Repeat with a loop

for (int number = 1; number <= 3; number++) {
    System.out.println(number);
}
