Python basics

Python is a popular programming language with a readable, beginner-friendly style. Start with these small building blocks.

1. Show output

Use print() to display text or a value.

print("Hello, world!")

2. Store a value

A variable gives a name to information you want to use later.

name = "Sam"
age = 20
print(name, age)
Tip: Python uses indentation to show which lines belong together. Use consistent spacing inside blocks.

3. Make a decision

An if statement runs code only when its condition is true.

temperature = 25
if temperature > 20:
    print("It's a warm day")
else:
    print("It's a cool day")

4. Repeat with a loop

A for loop can run once for each item in a sequence.

for number in range(1, 4):
    print(number)

5. Make a function

Functions package a useful action so you can call it by name.

def greet(name):
    return f"Hello, {name}!"

print(greet("Sam"))
